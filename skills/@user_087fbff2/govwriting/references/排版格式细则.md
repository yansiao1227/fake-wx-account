# 公文排版格式细则（GB/T 9704-2012 实用解读）

> 本文件基于 GB/T 9704-2012《党政机关公文格式》国家标准，提炼最实用的排版格式要求，供写作时参考。

---

## 一、页面设置

| 项目 | 要求 |
|------|------|
| 纸张 | A4型纸，成品幅面尺寸210mm×297mm |
| 页边距 | 上37mm±1mm，下35mm±1mm，左28mm±1mm，右26mm±1mm |
| 版心尺寸 | 156mm×225mm（不含页码） |
| 正文行数 | 一般每页22行，每行28字 |

---

## 二、字体字号

### 1. 标题
- **格式**：2号小标宋体字，居中排布
- **回行要求**：回行时，要做到词意完整，排列对称，长短适宜，间距恰当
- **多行标题**：第一行字数可以稍多，第二行以下字数相近，不要出现一行只有两三个字的情况

### 2. 主送机关
- **格式**：3号仿宋体字，顶格排布，回行时仍顶格
- **标点**：最后一个主送机关名称后标全角冒号

### 3. 正文
- **格式**：3号仿宋体字
- **段落**：每段左空2字，回行顶格
- **数字**：公文中使用阿拉伯数字（成文日期、印发日期等必须用阿拉伯数字）

### 4. 层次序号
| 层级 | 格式 | 说明 |
|------|------|------|
| 第一层 | "一、"（黑体字） | 一后面用顿号 |
| 第二层 | "（一）"（楷体字） | 括号后面不用标点 |
| 第三层 | "1."（仿宋体字） | 点后面不用顿号 |
| 第四层 | "（1）"（仿宋体字） | 括号后面不用标点 |

### 5. 附件说明
- **位置**：正文下空一行，左空2字编排"附件"二字
- **格式**：3号仿宋体字
- **序号**：附件顺序号用阿拉伯数字，如"附件：1. XX表"

### 6. 发文机关署名、成文日期、印章
- **发文机关署名**：以成文日期为准，居中排布
- **成文日期**：用阿拉伯数字，如"2024年5月20日"
- **印章**：端正、居中下压发文机关署名和成文日期，使发文机关署名和成文日期居印章中心偏下位置

### 7. 页码
- **格式**：4号半角宋体阿拉伯数字，左右各放一条一字线
- **位置**：版心下边缘之下，单页码居右空1字，双页码居左空1字

---

## 三、行距与间距

| 项目 | 要求 |
|------|------|
| 正文行距 | 28磅（可在28-30磅之间调整） |
| 标题与正文间距 | 标题下空1行 |
| 段落间距 | 段前0行，段后0行 |
| 附件说明与正文间距 | 正文下空1行写附件说明 |
| 发文机关署名与正文间距 | 一般空2-3行 |

---

## 四、装订要求

| 项目 | 要求 |
|------|------|
| 装订位置 | 左侧装订 |
| 装订方式 | 骑马订或平订 |
| 页码位置 | 骑马订钉位距书脊上下各1/4处；平订钉锯与书脊间的距离为3-5mm |
| 空白页 | 公文中表格排不下时，需另起一页的，应先附空白页，再排表格 |

---

## 五、常见格式错误及纠正

### 错误1：标题排布不合理
- **错误表现**：标题只有两个字就换行，或最后一行只有一个字。
- **纠正方法**：调整标题文字，或适当调整字间距，使排布美观。

### 错误2：层次序号使用不规范
- **错误表现**：第一层用"1."，第二层用"一、"等。
- **纠正方法**：严格按照"一、→（一）→1.→（1）"的顺序使用。

### 错误3：字体使用混乱
- **错误表现**：正文用了黑体，层次序号用了仿宋体等。
- **纠正方法**：严格按照标准要求使用字体，不要随意更换。

### 错误4：页码位置错误
- **错误表现**：页码放在版心内，或与文字太近。
- **纠正方法**：页码放在版心下边缘之下，单页码居右空1字，双页码居左空1字。

### 错误5：附件标注不规范
- **错误表现**：附件直接在正文中写"详见附件"，没有在文尾标注。
- **纠正方法**：在正文中用"（详见附件1）"标注，在文尾标注附件顺序和名称。

## 六、电子公文格式要求

| 项目 | 要求 |
|------|------|
| 文件格式 | PDF/A标准格式 |
| 元数据 | 包含发文机关、发文字号、标题、成文日期等 |
| 电子印章 | 符合国家标准，与纸质公文具有同等法律效力 |
| 归档要求 | 按电子文件归档与电子档案管理规范执行 |

- [ ] 是否左侧装订？

---

## 总结：格式规范的"三原则"

1. **严格按标准**：不随意创新，严格按GB/T 9704-2012标准执行。
2. **整体要美观**：排版整齐、间距合理、字体统一，给人美观大方的感觉。
3. **细节要做到**：标点符号、数字用法、层次序号等细节都要规范。
