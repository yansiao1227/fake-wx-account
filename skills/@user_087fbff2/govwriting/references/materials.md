## 一、公文写作自检清单（v3.0版）

### 写前自检（三问）
- [ ] **第一问**：这件事的根本问题是什么？——说不清楚的，稿子一定乱
- [ ] **第二问**：写完之后读者会有什么行动？——没有行动指向的稿子等于没写
- [ ] **第三问**：我是在替组织说话，还是在表达个人意见？——立场没站稳，文字越精彩越危险

### 提纲自检
- [ ] 核心观点能用一句话概括全文
- [ ] 逻辑层次分明，每部分有明确的功能
- [ ] 重点部分与非重点部分比例恰当
- [ ] 素材已预配到各观点下，不是边写边找材料

### 标题自检
- [ ] 标题=发文机关+关于+事由+文种，四要素齐全
- [ ] 标题能独立传达核心信息，不依赖正文补充
- [ ] 小标题之间逻辑并列或递进，不自相矛盾
- [ ] 避免三个小标题都用"一是/二是/三是"的结构

### 语言自检（五性）
- [ ] **严肃**——有没有轻浮、油滑、网络化的表达？
- [ ] **通俗**——非专业人员能不能听懂这段话的意思？
- [ ] **明快**——有没有冗余的过渡句和废话？
- [ ] **朴实**——有没有空洞的排比、表态代替措施？
- [ ] **泼辣**——有没有明确的观点和有力的结论？（最高要求）

### 格式自检（GB/T 9704）
- [ ] 标题：2号小标宋体，居中
- [ ] 正文：3号仿宋体
- [ ] 正文行距：28磅
- [ ] 层次序号：第一层"一、"、第二层"（一）"、第三层"1."、第四层"（1）"
- [ ] 页边距：天头37mm、地脚28mm、订口28mm、翻口26mm

### 审核自检（修改六步）
1. [ ] **找感觉**——通读全文，这篇稿子读起来顺不顺？
2. [ ] **查问题**——主题偏没偏？逻辑通不通？材料够不够？
3. [ ] **听意见**——有没有请教过有经验的同事？
4. [ ] **备材料**——数据准不准？引文对不对？
5. [ ] **改语言**——逐句打磨，删除所有可删的字
6. [ ] **核细节**——日期、人名、发文字号、标点符号

## 二、领导沟通8问·应对指南

### 问1：稿子自己满意却被领导退回
**诊断**：大多数时候，退回不是因为"写得差"，而是因为"站位偏"
**应对**：
- 先问自己：我是在替组织说话，还是夹带了个人想法？
- 检查立场：这份稿子代表谁？是站在单位角度还是个人角度？
- 放下技术思维，先回到问题本身：领导真正想表达的是什么？

### 问2：领导意图多变，改来改去
**应对**：
- 每次改动前，先口头确认："您看这样改是否准确？"
- 把领导的口头意见书面化，发给他确认，避免理解偏差
- 主动提供选择题而非问答题："A方向和B方向，您倾向哪个？"

### 问3：领导批评稿子像"漂汤油"
**诊断**："漂汤油"=有油花没有内容=有表态没有分析
**应对**：
- 每个判断后面必须跟事实、数据或案例
- 把"高度重视"替换为具体的数字和行动
- 自查：这段话删了，对全文有影响吗？没有就删

### 问4：领导要求新意，又反对标新立异
**应对**：
- 新意在共性中找：在普遍规律中找本单位特色
- 数据新、案例新、举措新，不等于概念新
- 守住格式规范，在内容深度上创新

### 问5：领导不满意又没明确意见
**应对**：
- 不要猜测，主动逐条询问："您觉得第二部分是否方向对？"
- 提供对比方案："原方案是A方向，我补充了B方向，您看哪个更合适？"
- 把稿子拆成几个模块，逐个确认

### 问6：领导亲自改稿出现错误
**应对**：
- 私下沟通，方式要婉转："某处可能需要再斟酌，是否我理解有误？"
- 把错误包装成问题，而不是指出："这个数据来源是否需要再核实？"
- 如果领导坚持，不在正式场合纠正，事后补充书面说明

### 问7：稿子书生气太重
**诊断**：只有概念、判断、理论，没有数据、事例、具体措施
**应对**：
- 每个观点配一个具体案例
- 把"取得显著成效"替换为具体的百分比和事件
- 增加一线场景的描写

### 问8：稿子信息量不大
**应对**：
- 压缩废话，每段必须有实质性信息
- 测试方法：每段话能不能用一句话概括核心意思
- 自查：读完这段，读者知道具体要做什么吗？

## 三、反面案例库（公文修改前后对照）

### 案例1：标题失败

**改前**：
> 关于召开会议的通知

**问题**：千篇一律，无法传达任何有效信息
**改后**：
> ××县关于召开2024年一季度经济运行分析会的通知

**点评**：四要素齐全，一看就知道是什么会议、什么时候开

---

### 案例2：开头冗长（"漂汤油"典型）

**改前**：
> 为认真贯彻落实党中央、国务院关于做好经济工作的决策部署，深入落实省委、省政府关于一季度经济工作的重要指示精神，切实加强对全县经济运行态势的分析研判，推动各级各部门进一步认清形势、统一思想、凝聚力量，确保全县经济工作开好局、起好步，经县委、县政府研究，决定召开本次会议。

**问题**：六行字还没说清开什么会
**改后**：
> 一季度经济运行压力较大，部分指标低于预期。为找准问题、统一认识、部署二季度工作，召开本次分析会。

**点评**：三句话交代背景和目的，开门见山

---

### 案例3：语言空洞

**改前**：
> 要加强领导，完善机制，强化措施，狠抓落实，确保各项工作取得实效。

**问题**：五个动词全是虚的，什么都没说清
**改后**：
> （一）强化统筹协调。成立由常务副县长任组长的工作专班，每两周调度一次进展。（二）完善考核机制。将"项目落地率"纳入部门年度考核，未达标的单位主要负责人作书面说明。

**点评**：每个要求后面必须有具体的数字、行动、责任人和时间节点

---

### 案例4：请示报告不分

**改前**：
> 关于请求拨付资金的报告
> 
> ……以上报告，请批示。
> （后附资金申请方案）

**问题**：文种是"报告"，但实际内容是"请示"（请求批准资金）
**改后**：
> 关于申请拨付××专项资金的请示
>
> ……妥否，请批复。

**点评**：
- 需要上级批准的事项→请示
- 汇报情况不需要批准→报告
- 二者不得混用

---

### 案例5：小标题空洞雷同

**改前**：
> 一、加强组织领导
> 二、加强制度建设
> 三、加强监督检查

**问题**：三个"加强"，三个帽子，内容毫无区分度
**改后**：
> 一、成立工作专班，压实"一把手"责任
> 二、修订考核细则，将进度纳入月通报
> 三、建立督查机制，对滞后单位开展约谈

**点评**：小标题要有实质内容，一看标题就知道这段要说什么

---

### 案例6：纪要写成会议记录

**改前**：
> 会上，张局长提出要重视这项工作，李副局长补充说要加强协调，王处长认为应该先把方案拿出来，大家进行了讨论……

**问题**：纪要不写讨论过程，只记结论
**改后**：
> 一、工作目标：6月底前完成方案制定，三季度启动实施。
> 二、责任分工：办公室负责统筹，××科室负责起草，××科室配合提供数据。
> 三、时间节点：4月15日前提交初稿，5月底前完成部门会签。

**点评**：纪要的铁律——不写讨论过程，只记议定结论

---

### 案例7：数据引用错误

**改前**：
> 去年全县GDP增长8.5%，增速位居全省第三。

**问题**：未经核实，凭记忆写的数字——如果错误，损失的是权威性
**改后**：
> 去年全县GDP增长8.5%（数据来源：县统计局2024年公报），增速位居全省第三（据省政府办公厅《2024年度各地市经济发展通报》）。

**点评**：所有数据必须注明来源；发文字号必须核对原文

---

### 案例8：违反保密规定

**改前**：
> 本次会议研究了以下事项：……（含具体金额、人事方案等内部信息）

**问题**：涉密内容不得写入正式公文的对外版本
**改后**：
> 本次会议研究了有关工作事项，会议议定事项将另行通知。

**点评**：公文有内外之分，对外公文的措辞和内容须经过保密审查

## 四、六类讲话稿语言范例

### 1. 部署性讲话（雄浑昂扬）

> 同志们，今年是贯彻落实党的二十大精神的关键之年，也是我们实现"十四五"规划目标的攻坚之年。逆水行舟，不进则退。我们没有退路，只有向前。
>
> 各级各部门要切实把思想和行动统一到县委、县政府的决策部署上来，以"开局即决战、起步即冲刺"的劲头，确保各项任务不折不扣落实到位。

**语言特点**：动词有力、节奏明快、有紧迫感、有号召力

---

### 2. 总结表彰性讲话（优美温暖）

> 过去一年，是我们克难奋进、收获满满的一年。这一年，干部群众用汗水浇灌收获，以实干笃定前行，涌现出一大批敢于担当、乐于奉献的先进典型。
>
> 今天受表彰的同志，是全县干部队伍的杰出代表。他们的事迹平凡而伟大，精神温暖而闪光。让我们以热烈的掌声，向他们致以崇高的敬意！

**语言特点**：肯定成绩有温度、表彰先进有情感、展望未来有希望

---

### 3. 座谈交流性讲话（平等和谐）

> 今天这个座谈会，我想主要听大家讲。有什么困难尽管提，有什么想法也可以说，咱们共同商量。
>
> 你刚才说的那个问题，我很认同。从你们镇的实践来看，确实趟出了一条好路子，可不可以总结一下，推广到其他乡镇？

**语言特点**：语气平等、不居高临下、肯定对方、引导讨论

---

### 4. 礼仪应景性讲话（轻松优雅）

> 各位嘉宾、各位朋友：
>
> 金秋时节，桂花飘香。今天我们相聚于此，共叙友谊、共谋发展。我谨代表县委、县政府，对各位的到来表示热烈的欢迎，对大家长期以来对××发展的关心支持表示衷心的感谢！

**语言特点**：简洁得体、有节日的仪式感、不拖沓、有真情实感

---

### 5. 调研汇报性讲话（精准实在）

> ××书记、××县长：
>
> 按照会议安排，我把全县一季度经济运行情况作个汇报。概括起来三句话：总体平稳、压力不小、后劲可期。
>
> 具体来说：一是主要指标稳中有进。GDP增长×%，排在全市第×位。二是问题不容忽视。工业增速回落×个百分点，居全市末位……

**语言特点**：结论先行、数据密集、语言精准、不绕弯子

---

### 6. 全会报告性讲话（宏观厚重）

> 同志们：
>
> 现在，我代表县委常委会，向全会作报告。
>
> 一、过去一年的工作回顾
>
> 这一年，我们遇到的困难比预料的多，取得的结果比预想的好。全年GDP突破×亿元，增长×%，创历史新高……

**语言特点**：全局视野、逻辑严密、语言庄重、有历史纵深感

## 五、AI写作质量评估量表

使用场景：AI完成初稿后，按以下维度打分，每项0-10分

| 维度 | 评估问题 | 得分 |
|------|---------|------|
| **立场** | 这篇稿子是在替组织说话吗？有没有夹带个人色彩？ | __/10 |
| **意图匹配** | 写之前有没有搞清楚领导真正想表达什么？ | __/10 |
| **角度** | 选的角度是否最有力、最有特色？ | __/10 |
| **结构** | 框架清晰吗？重点突出吗？逻辑通顺吗？ | __/10 |
| **内容** | 有没有实质信息（数据/案例/措施）？还是全是表态？ | __/10 |
| **语言** | 五性达标了吗？（严肃/通俗/明快/朴实/泼辣） | __/10 |
| **修改** | 经过六步修改法了吗？读改了吗？ | __/10 |

**总分60分以上**：可以提交
**总分70分以上**：优秀，可以作为范文积累
**总分不足50分**：需要推倒重来

## 七、文种写作框架速查（方法论提炼）

> 以下框架从公文写作方法论著作中提炼，适用于起草前搭骨架。不是范文，不含原文。

---

### 信息写作·三种框架

**经验类信息**

```
标题：做法 + 成效（10字以内，一句话）
结构：
  一、主要做法
    1. 主体做法（政府主导/制度设计）
    2. 协作机制（部门联动/多方参与）
    3. 保障措施（督查/考核/激励）
  二、主要成效
    - 数据说话：覆盖多少人、解决多少事、增长多少
```

框架检验：做法和成效各占一半；没有成效数据则不写经验类信息。

**建议类信息**

```
标题：问题 + 对策（10字以内）
结构：
  一、问题现状
    - 用数据或现象说明问题普遍性
  二、原因分析（2-3条）
    - 每条有具体表现，不说"认识不到位"
  三、对策建议（逐一对应原因）
    - 对策①解决原因①
    - 对策②解决原因②
```

框架检验：建议条数与原因条数相等；每条建议能解决一个具体问题。

**问题类信息**

```
标题：事件 + 性质 + 影响
结构：
  一、事实经过（何时何地发生何事，控制3句）
  二、问题性质（定性：属于哪类违规/失误）
  三、初步处理（已采取什么措施）
  四、启示建议（其他单位如何防范）
```

框架检验：事实经过不超过总篇幅1/3；重点在教训而非过程描述。

---

### 会议纪要·虚实结构法

```
结构（先虚后实）：

【虚——一致意见】
  会议认为……（判断和评价）
  会议指出……（问题揭示和形势分析）
  会议强调……（重要性认识）

【实——具体决定】
  会议明确……（某件事要怎么做）
  会议要求……（某项工作谁来干、什么标准）
  会议议定……（具体事项：责任人+时限）
```

**每项议定事项必须包含三要素：**
- 事项：做什么
- 责任：谁来做
- 时限：什么时候完成

**四忌：**
1. 忌不概括，把纪要写成会议记录
2. 忌写讨论过程，只记结论
3. 忌议定事项无时限、无责任人
4. 忌把纪要写成领导讲话稿（领导个人意见≠议定事项）

---

### 问题通报·四步结构

```
结构：
  一、基本情况（时间/地点/人物/事件，3-5句）
  二、问题性质（定性：暴露了什么突出问题）
  三、处理决定（对谁、处理什么、何时完成）
  四、工作要求（其他单位如何防范，2-3条）
```

**写作要点：**
- 事实叙述要客观，不加主观评论
- 问题定性要有依据（政策/制度/规定）
- 处理决定要具体（不是"严肃处理"而是"责成作书面检查"）
- 防范要求要有针对性（不是泛泛"举一反三"而是"在哪些环节自查"）

---

### 决议·两种写法

**决策性决议（重大问题）**

```
结构：
  一、作出决议的依据和背景
  二、目标任务（要实现什么）
  三、措施方法（怎么做）
  四、执行要求（谁来保障）
  [可选] 五、号召语
```

适用于：党的全会决议、关于某项重大工作的决定
语言特征："应当""必须"，语气庄重

**批准性决议（审议报告）**

```
结构：
  一、对报告/事项的基本评价（会议认为）
  二、批准决定（会议批准/原则同意）
  三、工作要求和希望（会议号召）
```

适用于：人大会议、政协会议审议工作报告
语言特征：大量使用"会议认为""会议号召"；篇幅短小，一般不用小标题

---


### 汇报材料·三层展开法

```
结构：
  一、基本情况（1段，让领导快速了解全貌）

  二、主要做法与成效（核心部分）
    按类别分，不按时间顺序
    每类：做法（怎么做的）+ 成效（数字说话）
    亮点前置

  三、存在问题与下一步打算（简洁，不喧宾夺主）
```

**三原则（写前必问）：**
- 少讲过程（开了多少会、研究了几次——几句带过）
- 多讲实质（结论、成效、问题）
- 讲重点特色（本单位独特做法，不是通用内容）

**"深准实紧"检验：**
- 深：问题抓得准，原因分析透
- 准：判断有数据或事实支撑
- 实：对策能落地
- 紧：逻辑环环相扣

### 经验介绍材料·两种写法

**写法A：夹叙夹议（推荐）**

```
结构：
  开头：亮出主题 + 主要成效（一段话）
  主体：以体会带做法，做法中有体会
    → 体会：为什么这么做（理念层）
    → 做法：具体怎么做的（操作层）
    → 成效：用数字和事例验证
  结尾：谦虚语 + 下一步打算
```

适用于：综合性经验、改革创新类

**写法B：做法与体会分开**

```
结构：
  开头：亮出主题 + 主要成效（一段话）
  主体一：主要做法（2-4条，每条有具体措施）
  主体二：体会认识（2-4条，每条有提炼升华）
  结尾：谦虚语 + 下一步打算
```

适用于：单项工作经验、专项行动总结

**经验介绍四标准：**
- 特色明显：写本地本单位的独特做法，不是通用经验
- 生动感人：有具体场景、数字、案例，不是干巴巴的总结
- 说服力强：成效有对比数字，不是自说自话
- 简洁明了：不超过3000字，不是越长越有分量

### 调研报告·蹲点式三段法

```
结构：
  一、感动（看到了什么）
    → 现场场景 + 数字 + 群众语言（引用1-2句原话）

  二、触动（想到了什么）
    → 对比分析（现状 vs 问题 vs 潜力）
    → 数据对比、案例对比

  三、行动（准备怎么做）
    → 借鉴外地经验的具体路径
    → 结合本地实际的创新做法
    → 重点工作的2-3项关键举措
```

**蹲点调研的特殊要求：**
- 必须有一线场景和细节（不是坐在办公室里想象）
- 必须有群众或基层干部的原话（增加真实感）
- 启示部分必须紧扣前面考察内容，不能另起炉灶
