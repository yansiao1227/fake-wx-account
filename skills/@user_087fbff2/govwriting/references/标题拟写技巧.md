# 公文标题拟写技巧

> 本文件收录公文标题拟写的实用技巧,帮助提升标题的吸引力和表达力。

---

## 一、对仗式标题
- **要求**:上下句字数相同、结构相似、意义相关。
- **适用场景**:工作报告、部署文件、经验交流材料等。
- **示例**:
  - "锚定目标抓落实,聚焦重点求突破"
  - "强化担当意识,提升履职能力"
  - "稳字当头夯基础,进字为要促发展"

---

## 二、数字式标题
- **要求**:用数字概括核心内容,简洁明了。
- **适用场景**:工作要点、任务清单、总结报告等。
- **示例**:
  - "六个聚焦"(聚焦政治建设、聚焦经济发展...)
  - "五项机制"(建立健全责任机制、督查机制...)
  - "三个强化"(强化组织领导、强化工作举措、强化督导考核)

---

## 三、问题导向式标题
- **要求**:直接点明问题,吸引注意力。
- **适用场景**:调研报告、问题通报、整改方案等。
- **示例**:
  - "关于XX问题的调研与思考"
  - "XX工作存在的突出问题及对策建议"
  - "当前XX领域面临的三大挑战及应对思路"

---

## 四、形象化标题
- **要求**:用比喻、拟人等修辞手法,生动形象。
- **适用场景**:动员讲话、宣传材料、经验交流等。
- **示例**:
  - "打好组合拳,奏响协奏曲"
  - "跑出加速度,创出新业绩"
  - "织密防护网,筑牢安全墙"

---

## 五、政策式标题
- **要求**:紧扣政策文件,体现政治站位。
- **适用场景**:贯彻落实类文件、工作意见、实施方案等。
- **示例**:
  - "深入贯彻落实XX精神,扎实推进XX工作"
  - "以XX为指导,推动XX高质量发展"
  - "对标对表XX要求,全面提升XX工作水平"

---

## 六、成效式标题
- **要求**:突出工作成效,体现工作价值。
- **适用场景**:工作总结、经验交流、汇报材料等。
- **示例**:
  - "XX工作取得显著成效,多项指标位居全省前列"
  - "创新举措破难题,XX工作迈上新台阶"
  - "聚焦民生实事,XX工作群众满意度持续提升"

---

## 七、任务式标题
- **要求**:明确工作任务,体现行动导向。
- **适用场景**:工作部署、任务分解、实施方案等。
- **示例**:
  - "关于加快推进XX工作的实施意见"
  - "XX工作三年行动计划(2024-2026年)"
  - "全力抓好XX工作,确保完成全年目标任务"

---

## 八、经验式标题
- **要求**:提炼经验做法,体现示范价值。
- **适用场景**:经验交流、典型发言、工作简报等。
- **示例**:
  - "坚持三个强化,推动XX工作高质量发展"
  - "创新四项机制,破解XX工作难题"
  - "聚焦五个重点,提升XX工作实效"

---

## 九、警示式标题
- **要求**:警示风险问题,体现紧迫性。
- **适用场景**:问题通报、整改通知、风险提醒等。
- **示例**:
  - "关于XX问题的通报"
  - "当前XX工作面临的严峻形势及应对要求"
  - "警钟长鸣,切实抓好XX工作"

---

## 十、号召式标题
- **要求**：发出号召倡议，体现动员性。
- **适用场景**：动员讲话、倡议书、宣传材料等。
- **示例**：
  - "动员全市力量，加快推进XX建设"
  - "携手共建美好家园，奋力谱写XX发展新篇章"
  - "汇聚磅礴力量，推动XX工作再上新台阶"

## 十一、形象化对称标题范例（精选）

| 类别 | 范例 |
|------|------|
| **动词+名词对称式** | 拧紧“总开关”；常打“预防针”；铺设“高压线”；凝聚“正能量”；明确“风向标” |
| **比喻引领式** | 画出共同理想“同心圆”；筑牢社会文明“压舱石”；找准改革发展“公约数”；彰显市北新城“精气神” |
| **问题导向式** | 在“系统化”领悟中把握精髓要义；在“精准化”组学中增强落实效果；在“通俗化”解读中抓好平台对接 |
| **成效展示式** | 强基固本，画出共同理想“同心圆”；崇德向善，筑牢社会文明“压舱石”；引领舆论，找准改革发展“公约数” |
| **任务部署式** | 上下同欲，举好发展“指挥棒”；突出重点，做对管理“运算符”；融合优化，用足提升“工具箱” |
| **方法策略式** | 勤于做“加法”，重点是补短板；勇于做“减法”，重点是降不良；善于做“乘法”，重点是建制度；敢于做“除法”，重点是控成本 |
| **保障落实式** | 高度重视，提起党务公开的“领子”；健全机制，拉好党务公开的“链子”；全面公开，掀开党务公开的“底子”；发动群众，摆开党务公开的“场子” |
| **创新举措式** | 督导检查组现场“健康筛查”；微信观察员进群“远程检测”；质量抽检员随机“抽样检查” |
| **问题导向式** | 开好分类施策“药方”；照好先进典型“镜子”；搭建以学促做“平台” |
| **队伍建设式** | “正气”，就是有共产党员的本色；“帅气”，就是要注重形象；“底气”，要处事不惊、沉着冷静；“灵气”，要开动脑筋、灵活创新 |

**写作技巧**：
1. **找准喻体**：选择与工作内容相关的形象比喻（如“指挥棒”对应领导，“压舱石”对应基础）
2. **保持对称**：上下句字数相同、结构相似、意义相关
3. **避免生硬**：比喻要自然贴切，不牵强附会
4. **适度使用**：一篇材料中使用2-3处即可，过多会显得浮夸
