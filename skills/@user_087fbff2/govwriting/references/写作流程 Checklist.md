# 公文写作全流程 Checklist

> 本文件提供从接到写作任务到最终定稿的完整工作流程清单，帮助写作者有条不紊地完成写作任务。

---

## 第一阶段：写前准备（占成功率的50%）

### 1. 明确任务要求
- [ ] **明确写作目的**：为什么要写这个文件？要解决什么问题？
- [ ] **明确文种**：应该用什么文种？（请示/报告/通知/函/纪要等）
- [ ] **明确读者**：文件是给谁看的？（上级领导/平行单位/下级单位）
- [ ] **明确内容范围**：要写哪些内容？不写哪些内容？
- [ ] **明确篇幅要求**：大概写多少字？
- [ ] **明确完成时限**：什么时候要交稿？

### 2. 搜集背景资料
- [ ] **上级文件**：收集相关的上级政策文件、会议精神、领导讲话。
- [ ] **本单位情况**：收集本单位相关工作数据、进展情况、存在问题。
- [ ] **外地经验**：收集外地同类工作的做法和经验（如有需要）。
- [ ] **典型案例**：收集相关的典型案例、正反两方面事例。
- [ ] **数据资料**：收集相关的工作数据、统计报表、调研结果。

### 3. 确认领导意图
- [ ] **当面汇报**：主动向领导汇报写作思路，确认是否符合要求。
- [ ] **询问重点**：领导最关心什么？最想突出什么？
- [ ] **确认风格**：领导喜欢什么风格？（务实型/激情型/严谨型）
- [ ] **确认框架**：大的框架结构是否合适？

### 4. 列出写作提纲
- [ ] **确定核心观点**：这篇文件的核心观点是什么？能用一句话概括吗？
- [ ] **确定结构框架**：按什么逻辑安排结构？（时间顺序/重要性顺序/问题导向）
- [ ] **分配内容板块**：每个部分写什么内容？大致多少字？
- [ ] **预配素材**：每个观点下准备用什么素材支撑？（数据/事例/引用）

**✅ 完成标志**：提纲得到领导认可，可以开始动笔。

---

## 第二阶段：初稿写作（占成功率的30%）

### 1. 搭建框架
- [ ] **写好标题**：标题是否准确、醒目、简洁？
- [ ] **写好开头**：开头是否简明扼要，直接切入主题？
- [ ] **写好主体**：按提纲展开，每个部分是否完成了预定功能？
- [ ] **写好结尾**：结尾是否有力，符合文种要求？

### 2. 填充内容
- [ ] **用数据说话**：关键成效是否有数据支撑？
- [ ] **用事例证明**：重要观点是否有具体事例？
- [ ] **用引用增色**：是否恰当引用了政策文件或领导讲话？
- [ ] **避免空话套话**：是否删除了没有实质内容的表态话？

### 3. 初稿自查
- [ ] **内容完整性**：是否涵盖了所有要求的内容？
- [ ] **逻辑连贯性**：前后是否连贯？有没有跳跃？
- [ ] **观点正确性**：观点是否符合政策要求？数据是否准确？
- [ ] **篇幅适当性**：是否控制在要求的篇幅范围内？

**✅ 完成标志**：初稿完成，内容基本完整。

---

## 第三阶段：修改润色（占成功率的15%）

### 1. 内容修改
- [ ] **核对政策依据**：引用的政策文件是否准确？文号、标题、内容是否无误？
- [ ] **核实数据**：所有数据是否经过核实？来源是否可靠？
- [ ] **检查逻辑**：因果关系是否成立？论证是否充分？
- [ ] **删除冗余**：有没有重复的内容可以合并？有没有无关的内容可以删除？

### 2. 语言打磨
- [ ] **检查"五性"**：
  - [ ] 严肃性：有没有轻浮、油滑的表达？
  - [ ] 通俗性：非专业人员能看懂吗？
  - [ ] 明快性：有没有冗余的过渡句和废话？
  - [ ] 朴实性：有没有空洞的排比和表态？
  - [ ] 泼辣性：有没有明确的观点和有力的结论？
- [ ] **检查"十弊"**：
  - [ ] 有没有"大概""可能"等模糊词语？
  - [ ] 有没有"极其""最最最"等夸张词语？
  - [ ] 有没有网络语言、方言土语？
  - [ ] 有没有歧义词语？
- [ ] **优化标题**：小标题是否整齐、吸引人？

### 3. 格式规范
- [ ] **检查文种格式**：是否符合所选文种的格式要求？
- [ ] **检查层次序号**：是否按规范使用"一、→（一）→1.→（1）"？
- [ ] **检查字体字号**：标题、正文、层次序号的字体字号是否规范？
- [ ] **检查标点符号**：标点使用是否规范？
- [ ] **检查数字用法**：数字使用是否规范？

**✅ 完成标志**：稿子经过至少两遍修改，内容和语言都达到较好水平。

---

## 第四阶段：审核定稿（占成功率的5%）

### 1. 领导审阅
- [ ] **主动送审**：将修改好的稿子送领导审阅。
- [ ] **记录意见**：领导提出的修改意见是否全部记录？
- [ ] **理解意图**：领导为什么提出这些意见？要往哪个方向改？

### 2. 修改完善
- [ ] **逐条修改**：对领导提出的意见逐条修改，不遗漏。
- [ ] **再次通读**：修改后再次通读全文，检查是否连贯。
- [ ] **避免硬伤**：有没有错别字、错误数据、错误引用？

### 3. 最终定稿
- [ ] **格式最终检查**：页面设置、字体、字号、行距、页码等是否完全规范？
- [ ] **附件检查**：如果有附件，附件格式是否规范？与正文是否配套？
- [ ] **打印预览**：打印预览效果是否良好？
- [ ] **最终校对**：最好请同事帮忙校对一遍，避免盲区。

**✅ 完成标志**：稿子得到领导最终认可，可以正式发文。

## 不同文种的流程侧重

| 文种 | 准备阶段侧重 | 写作阶段侧重 | 修改阶段侧重 |
|------|--------------|--------------|--------------|
| **请示** | 明确请示事项和依据 | 理由充分、事项明确 | 检查是否一文一事、结尾用语是否规范 |
| **报告** | 搜集全面、准确的数据 | 突出重点、详略得当 | 检查是否夹带请示事项 |
| **通知** | 明确工作任务和责任人 | 要求具体、可操作 | 检查是否明确了完成时限和考核要求 |
| **函** | 明确商洽事项和依据 | 语气平等、用词精准 | 检查是否符合不相隶属关系 |
| **纪要** | 准确记录会议议定事项 | 纪实、扼要、条理清晰 | 检查是否明确了责任单位和完成时限 |
| **领导讲话稿** | 研究领导语言习惯 | 节奏合适、留出停顿空间 | 检查数据是否准确、是否有念错的风险 |

## 时间管理建议

| 任务难度 | 建议时间分配 | 说明 |
|----------|--------------|------|
| **简单任务**（如简短通知） | 准备30%、写作50%、修改20% | 重点在快速成文 |
| **中等任务**（如工作情况报告） | 准备40%、写作40%、修改20% | 平衡各环节 |
| **复杂任务**（如领导讲话稿） | 准备50%、写作30%、修改20% | 重点在想清楚再写 |

---

## 常见时间浪费陷阱

1. **接到任务马上动笔**：没想清楚就写，后面大量修改，反而更费时间。
2. **追求初稿完美**：初稿就是用来修改的，不要在不完美的地方浪费太多时间。
3. **不敢送审**：怕被领导批评，一直自己憋着改，反而错过最佳沟通时机。
4. **反复调整格式**：先把内容写好，最后统一调整格式，不要写一句调一句格式。

---

## 总结：成功写作的"三字经"

**准备阶段**：问清楚、查全面、想明白、列提纲。
**写作阶段**：搭框架、填内容、写到位、自查完。
**修改阶段**：核依据、磨语言、规范式、删冗余。
**定稿阶段**：送审阅、改意见、终校对、可发文。
