# 公文写作提纲框架（按文种分类）

> 本文件收录各文种通用的写作提纲框架，供写作时参考选用，可根据实际情况调整。

---

## 一、汇报材料提纲框架

### 框架一：成效-问题-打算（通用型）
1. 工作成效（主要指标完成情况、重点任务推进情况、亮点特色工作）
2. 存在问题（突出问题表现、原因分析、下一步工作思路）
3. 下一步打算（总体目标、重点任务、保障措施）

### 框架二：做法-成效-经验（经验交流型）
1. 主要做法（组织领导、工作举措、保障机制）
2. 工作成效（数据指标、典型案例、群众反馈）
3. 经验启示（规律性认识、可复制推广的做法）

### 框架三：问题-原因-对策（问题汇报型）
1. 存在的突出问题（具体表现、数据支撑、案例说明）
2. 问题产生的原因（主观原因、客观原因、体制机制原因）
3. 下一步对策建议（针对性措施、长效机制、请求支持的事项）

---

## 二、调研报告提纲框架

### 框架一：基本情况-问题-建议（通用型）
1. 调研概况（时间、地点、对象、方法、样本量）
2. 基本情况（调查对象的客观描述、主要成效、典型经验）
3. 问题分析（揭示规律、分析原因、问题性质）
4. 对策建议（针对性、可操作、长效机制）

### 框架二：总结经验类调研报告
1. 经验背景（经验来源、推广价值）
2. 主要做法（具体举措、保障机制）
3. 取得成效（数据指标、典型案例、社会反响）
4. 经验启示（可复制推广的内容、注意事项）

### 框架三：揭示问题类调研报告
1. 问题现状（具体表现、数据支撑、典型案例）
2. 原因分析（主观原因、客观原因、体制机制原因）
3. 危害影响（对工作、对群众、对发展的影响）
4. 对策建议（针对性措施、长效机制、政策建议）

---

## 三、领导讲话稿提纲框架

### 框架一：工作会议讲话
1. 开场（切题入题，3-5分钟）
2. 肯定成绩（统一认识，2-3分钟）
3. 分析问题（认清形势，5-8分钟）
4. 部署工作（核心部分，10-20分钟）
5. 提出要求（落实保障，3-5分钟）
6. 结尾（号召或总结，1-2分钟）

### 框架二：动员部署讲话
1. 开头（简短有力，说明会议目的）
2. 为什么做（重要意义、现实需要、上级要求）
3. 做什么（目标任务、重点工作、责任分工）
4. 怎么做（保障措施、时间节点、督导考核）
5. 结尾（表态坚定，发出号召）

### 框架三：总结表彰讲话
1. 开头（肯定成绩，语气温暖）
2. 总结经验（不是只说“做了以下工作”，要提炼规律性认识）
3. 表彰先进（典型事迹、示范作用）
4. 展望未来（下一步目标、工作要求）
5. 结尾（鼓舞人心，发出号召）

---

## 四、工作总结提纲框架

### 框架一：全面工作总结
1. 工作总体情况（指导思想、工作思路、推进情况）
2. 重点工作完成情况（指标完成情况、重点任务推进情况、亮点工作）
3. 存在的问题（突出问题、原因分析）
4. 下一步工作打算（总体目标、重点任务、保障措施）

### 框架二：专项工作总结
1. 工作背景（上级要求、现实需要、工作目的）
2. 主要做法（工作举措、保障机制、创新点）
3. 取得成效（数据指标、典型案例、上级肯定、群众反馈）
4. 存在不足（突出问题、原因分析）
5. 下一步计划（改进措施、工作打算）

---

## 五、通知提纲框架

### 框架一：工作部署类通知
1. 通知目的（为什么做）
2. 工作任务（做什么、责任单位、完成时限）
3. 工作要求（保障措施、督导考核、注意事项）
4. 附件（相关表格、材料清单等）

### 框架二：会议通知
1. 会议目的（为什么开）
2. 会议时间、地点、参会人员
3. 会议议程
4. 有关要求（报名方式、材料准备、注意事项）

---

## 六、请示提纲框架

1. 请示事由（为什么请示）
2. 请示事项（具体请求、依据、必要性）
3. 恳请事项（明确请求上级批复的内容）
4. 附件（相关材料、数据支撑等）

---

## 七、报告提纲框架

### 框架一：工作情况报告
1. 工作总体情况（指导思想、工作思路、推进情况）
2. 重点工作完成情况（指标完成情况、重点任务推进情况、亮点工作）
3. 存在的问题（突出问题、原因分析）
4. 下一步工作打算（总体目标、重点任务、保障措施）

### 框架二：事件情况报告
1. 事件基本情况（时间、地点、涉及人员、事件经过）
2. 事件处置情况（已采取的措施、取得的成效、存在的问题）
3. 下一步工作打算（事件处置、责任追究、长效机制建设）

---

## 八、函提纲框架

1. 函商事由（为什么发函）
2. 商洽事项（具体请求、依据、必要性）
3. 有关说明（相关背景、数据支撑、协作需求）
4. 联系方式（联系人、电话、邮箱等）
