# 公文修改七步法

## 八、公文修改七步法



### 自查七步（按顺序检查）



**第一步：查文种**——选对了文种吗？标题四要素齐全吗？

**第二步：查主送**——主送机关正确吗？需要抄送吗？

**第三步：查逻辑**——框架清晰吗？层次分明吗？

**第四步：查事实**——数据准确吗？事实属实吗？政策依据对吗？

**第五步：查语言**——对照"五性"标准，有无"十弊"？

**第六步：查格式**——标题/正文/落款符合GB/T 9704标准吗？

**第七步：查错字**——通读一遍，检查错别字和标点错误。



### 修改优先级



| 优先级 | 内容 | 要求 |

|--------|------|------|

| P0 | 事实/数据/政策表述 | 必须绝对准确 |

| P1 | 观点/结论/定性表述 | 经得起推敲 |

| P2 | 语言/格式/标点 | 规范工整 |

## 九、AI润色工作流（v3.0.0 更新）



### 流程一：初稿诊断



**四步检查：**

1. 格式诊断（文种/标题/主送/层次序号）

2. 内容诊断（要素齐全/逻辑清晰/依据充分）

3. 语言诊断（规范/无模糊/语气得当）

4. 输出诊断报告（P0/P1/P2优先级排列）



**诊断指令模板：**

'''

请帮我诊断以下公文初稿，从以下方面检查：

1. 格式规范性

2. 内容完整性

3. 语言规范性

4. 其他需要改进的地方



按P0（必须修改）/P1（建议修改）/P2（可选修改）列出问题，并给出具体修改建议。



[粘贴初稿]

'''



### 流程二：逐段润色



**四步：**

1. 润色开头（切题入题，不超过3句话）

2. 润色主体（按层次逐段，删除冗余，调整语序）

3. 润色结尾（有力，与开头呼应）

4. 润色标题（准确概括，有冲击力）



**润色指令模板：**

'''

请帮我润色以下公文。

重点修改以下问题：

[列出诊断出的问题]



润色要求：

- 删除所有可删的冗余表述

- 替换不规范用语

- 调整语序使逻辑更清晰

- 保持公文正式语气



[粘贴初稿]

'''



### 流程三：整体审视



**两步：**

1. 通读全文（流畅性/连贯性/一致性）

2. 重点核查（数据/人名/地名/日期/引用文件）

## 十、附录：常用词语规范



### 结束语对照表



| 文种 | 规范结束语 |

|------|-----------|

| 通知 | 请认真贯彻执行。/请遵照执行。 |

| 报告 | 以上报告，请审阅。 |

| 请示 | 以上请示，妥否，请批示。 |

| 批复 | （不写结束语） |

| 函 | 请予函复。/请研究函复。 |

| 意见 | 请结合实际，认真贯彻落实。 |

| 纪要 | （不写结束语） |



### 时间写法规范



- 用"XXXX年XX月XX日"，不用"XXXX年X月X日"

- 用"自XX年XX月XX日起"，不用"从XX年XX月XX日起"

- 用"及时"（限定近期），不用"不日"（含义模糊）



### 范围写法规范



- 用"各"不用"各个"（"各部门"）

- 用"均"表示无例外，不用"都"

- 用"以上""以下"要明确含不含本数



### 四字格常用词



统筹兼顾、综合协调、整体推进、分步实施、突出重点、攻克难点、

开拓创新、求真务实、真抓实干、依法依规、从严从实、稳中求进、

守正创新、提质增效、全面覆盖、精准发力、长效机制、齐抓共管

## 写作成长路径（v3.0.0 新增）



### 三道关：秘书成长的必经阶段



1. **知情关**：知道领导在想什么、单位在干什么

2. **适应关**：能把领导的思路"翻译"成文字

3. **基础关**：扎实的知识积累和写作基本功



### 坚持"三勤"



- **勤积累**：天天记录，周周整理

- **勤练笔**：每篇都是训练机会

- **勤比较**：把自己的稿子和高手的稿子对照看



### 做到"四不"



- 不怕失败（退稿是进步的阶梯）

- 不固步自封（好稿子永远在下一篇）

- 不三心二意（选定角度，全力突破）

- 不闭门造车（先问清楚再动笔）
