# 常用事务性公文（下）

### 5.8 竞职演讲/述职报告（v3.0.0 新增，v3.1.1 扩充）



> 竞职演讲是最特殊的演讲——它是"赛场竞马"，要在最短时间内让评委记住你、信任你。



**竞职演讲结构（扩充版）：**



===

开场（感谢+自我介绍，简洁，30秒内）

  → 姓名、现任职务、在岗时间

  → 不要冗长的感谢词



竞争优势（为什么是我，核心部分）

  → 经历：做过什么（与竞选岗位相关的经历）

  → 能力：能做什么（用事实证明，不用形容词）

  → 实绩：做成过什么（数字：XX项/XX次/XX%）



工作思路（当选后打算怎么干）

  → 目标明确（第一年/第二年分别实现什么）

  → 路径清晰（不是"加强学习"，是"重点抓XX工作"）



结尾（表态谦恭）

  → "请代表监督，请组织和同志们检验"

  → 切忌"请多关照"

===



**竞职演讲四要素（标杆范文评析精华）：**



| 要素 | 含义 | 具体表现 |

|------|------|---------|

| 自信而不失谦和 | 敢于展示，但不狂妄 | "我不是最优秀的，但我是最努力的" |

| 平实而不失风雅 | 有文采，但不用生僻词 | 对仗工整，但不是掉书袋 |

| 语势畅达 | 节奏感强，适合口头表达 | 长短句交错，有快有慢 |

| 有具体事实支撑 | 不用"工作能力强" | "起草各类材料XX份，获得领导批示XX次" |



**结尾对联法（竞职专用技巧）：**

> 用自编对联结尾，可以展示文采，给评委留下深刻印象。



示范：

- 上联：胜固可喜，宠辱不惊看花开

- 下联：败亦无悔，去留无意随云卷

- 横批：与时俱进

**述职报告结构（扩充版）：**



===

一、岗位职责（我负责什么，1段话）

二、主要工作及成效（核心，用数据说话，重点突出）

三、廉洁自律情况（述廉报告必须有，具体写）

四、存在的问题和不足（写实，不推卸，不回避）

五、下一步整改打算（方向明确，措施具体）

===



**述职报告自我评价三原则：**

1. **脉络要清晰**——每个部分只说一层意思，不混

2. **评价要坦诚**——不是"在领导的关怀下"，是"我自己做了什么"

3. **不足要写实**——不是"理论学习有待加强"，而是"理论学习停留于浅尝辄止，联系实际不够"



**述职报告数据支撑技巧：**

- 写成效：用对比——"原来……现在……"

- 写工作量：用绝对数——"处理来信来访XX件次"

- 写质量：用获奖或批示——"XX工作被评为省级先进"





### 5.8b 述职述廉报告（v3.1.1 新增）



> 述职述廉报告是述职报告的升级版，增加了廉洁自律部分，是干部年度考核和换届考察的标配文种。



**结构：**

===

一、岗位职责（我是谁，管什么）

二、主要工作及成效（用数据说话，重点突出）

三、廉洁自律情况（必须有，具体写：拒收礼金X次、X万元；从未参与赌博/公款吃喝；家属从业情况）

四、存在的问题和不足（写实，不回避，不推卸）

五、下一步整改打算（方向明确，措施具体）

===



**述职述廉写作三原则（来自谢亦森标杆范文）：**



1. **脉络要清晰**——每个部分只说一层意思，不混

2. **自我评价要坦诚**——不是"在领导的关怀下"，而是"我自己做了什么"

3. **不足要写得实**——不是"理论学习有待加强"，而是"理论学习停留于浅尝辄止，联系实际不够"



**常见错误：**

- 把述职写成功劳簿（只讲成绩，不讲问题）

- 把廉洁自律写成表态（"坚决拥护党的领导"——这不是述廉，是政治表态）

- 述廉部分缺失或空洞（领导念这个部分时，台下会特别关注）



**标杆述廉表述示范：**

> "一年来，严格遵守中央八项规定精神，从未参与赌博和公款吃喝玩乐等活动，从未出现'吃、拿、卡、要'行为；拒收礼金X次，合计X万元；从未利用职务之便为自己谋取不正当利益。"

### 5.9 经验介绍材料（v3.1.1 新增）



> 把一个地方、一个单位的好做法好成效总结出来，供其他地方学习借鉴。是考察报告和工作总结的近亲，但写法侧重点不同。



**经验介绍材料的两个本质特征：**

1. **可学性**——写出来的经验，其他地方照着做也能做到

2. **可复制性**——有具体的操作方法，不是空道理



**结构：**

===

一、基本情况（简要交代背景：这是一个什么地方、面临什么困难或机遇）

二、主要做法（核心部分：具体怎么做的，要有细节）

三、取得成效（用数据说话：改变了什么）

四、经验启示（不是空话，是可操作的规律性认识）

===



**经验介绍写作四步法：**



**第一步：找准"这一个"亮点**

- 这个地方的经验，和其他地方相比，独特之处在哪里？

- 写经验介绍最忌讳的是："加强领导、完善机制"——这是每个单位都在做的事，没有独特性。



**第二步：用具体数字和事实支撑做法**

- 不好："我们注重创新工作方式"

- 好："我们在全省率先推行'多员合一'生态管护员制度，将原来分散在3个部门的管护职能整合为一个岗位"



**第三步：成效要有比较**

- 和过去比："原来……现在……"

- 和其他地方比："全省唯一……"

- 有排名最好："位居全省第一/前列"



**第四步：经验提炼要有操作性**

- 不好："坚持党的领导是关键"

- 好："关键是要有一把手亲自挂帅、纳入年度考核、配备专职人员"



**经验介绍材料三忌：**

1. 忌写成政府工作报告（面面俱到，没有侧重点）

2. 忌写成工作总结（重做法轻成效，重过程轻规律）

3. 忌经验泛化（"坚持改革开放"不是具体经验，是基本常识）



**经验介绍标杆标题：**

- 《从"九龙治水"到"全域管控"——XX县生态管护员制度创新实践》

- 《呼应群众诉求 加强源头治理 促进和谐稳定——XX区社会治理创新探索》
