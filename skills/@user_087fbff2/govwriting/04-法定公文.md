# 15种法定公文模板

> 本文件包含 15 种法定公文的模板与典型实例。实例均为虚构，仅供写作参考。
> 完整反面案例与范例库见 `references/materials.md`。

---

## 一、请示

### 模板

```

关于[事项]的请示

[主送机关]：

一、背景/缘由
   [说明依据和必要性]

二、请示事项
   [明确具体地提出请求]

三、建议方案（如有）
   [提出解决建议供参考]

四、恳请事项
   [恳请批示/恳请批准]

[落款]
[日期]

```

**要点：** 一事一请，理由充分，建议具体，语气恭敬但不卑微。

### 典型实例

```

关于申请拨付农村人居环境整治专项资金的请示

县财政局：

一、背景与依据
   根据《省农村人居环境整治提升五年行动实施方案》（X政发〔2024〕15号）要求，我县须于2025年6月底前完成县域内15个重点村的生活污水治理设施建设，所需资金纳入年度预算统筹安排。

二、请示事项
   申请拨付农村人居环境整治专项资金共计480万元，专项用于15个重点村的生活污水管网铺设及终端处理设施建设。

三、资金测算
   管网铺设：约320万元（按每村平均21.3万元测算）
   终端设施：约160万元（按每村10.7万元测算，含设备采购及安装）
   具体预算明细见附件。

四、恳请事项
   妥否，请批示。

                        ××县农业农村局
                        2025年3月12日

（附件：资金测算明细表×份）

```

## 二、报告

### 模板

```

关于[事项]的报告

[主送机关]：

一、基本情况
二、主要工作及成效
三、存在的问题
四、下一步打算

```

**要点：** 实事求是，数据说话，报告不夹带请示事项。

### 典型实例

```

关于2024年一季度经济运行情况的报告

县政府：

一、一季度经济运行基本情况
   一季度全县实现地区生产总值23.6亿元，同比增长7.2%，增速较去年同期提高1.4个百分点。其中：第一产业增长3.1%，第二产业增长8.5%（规上工业增长9.2%），第三产业增长6.8%。

二、主要工作及成效
   一是工业经济企稳回升。新增规上企业3家，规上工业产值达16.8亿元。完成工业投资4.2亿元，同比增长12.3%。二是项目投资稳步推进。一季度新入库项目12个，总投资额18.5亿元；省重点项目开复工率达91%。三是市场消费持续回暖。实现社会消费品零售总额9.7亿元，增长8.1%。

三、存在的突出问题
   一是固定资产投资增速回落至5.1%，低于年度目标2.9个百分点，主要受房地产投资下滑拖累。二是部分规上企业面临出口订单下降压力，1-2月出口额同比下降6.3%。

四、下一步打算
   下一步重点抓好三项工作：一是加快产业转型，出台支持制造业高质量发展若干措施；二是强化招商引资，确保上半年新签约项目不少于8个；三是优化营商环境，对重点企业实行"一企一策"跟踪服务。

                        ××县发展和改革局
                        2024年4月8日

```

## 三、通知

### 模板

```

关于[事项]的通知

[主送机关]：

一、背景/依据
二、通知事项
三、落实要求（责任、时限）

```

**要点：** 要求具体可操作，责任到人，时限明确。

### 典型实例

```

关于切实做好2024年防汛抗旱工作的紧急通知

各乡镇人民政府、街道办事处，县直各部门：

一、充分认清形势
   据气象部门预测，2024年主汛期（6-8月）全县降水量较常年同期偏多1-2成，局部地区可能出现极端强降雨天气，防汛形势不容乐观。

二、重点工作要求
   （一）全面排查隐患。5月20日前完成全县病险水库、险工险段、低洼易涝区的拉网式排查，建立隐患台账，逐项整改销号。
   （二）强化监测预警。气象、水文部门加强会商研判，确保重要天气信息提前24小时发布；各乡镇要利用村村响、微信群等渠道将预警信息传递到村、到户、到人。
   （三）落实应急保障。县级防汛物资储备库要按标准补齐物资，各乡镇须在5月底前完成村级防汛抢险队伍组建并开展一次实战演练。

三、责任分工
   各乡镇政府主要负责人为本地区防汛抗旱工作第一责任人，分管领导具体抓落实。对因责任不落实、工作不到位造成人员伤亡和重大财产损失的，严肃追究相关责任人责任。

四、报送要求
   请各乡镇于5月25日前将防汛隐患排查整改情况报县防汛抗旱指挥部办公室（设在县应急管理局）。

                        ××县人民政府办公室
                        2024年5月10日

```

## 四、通报

### 模板

```

一、事实经过
二、定性评价
三、处理/工作要求
四、希望/警示

```

### 典型实例（批评通报）

```

关于对××镇耕地保护工作不力问题的通报

各乡镇人民政府、街道办事处：

一、基本情况
   经省自然资源厅2024年第一季度卫片执法监测，××镇辖区内共发现违法占用耕地行为3起，涉及耕地面积12.7亩，其中永久基本农田4.3亩。截至4月15日，上述违法用地均未完成整改。

二、问题性质认定
   ××镇政府在耕地保护工作中存在以下问题：一是日常巡查责任落实不到位，未能及时发现和制止违法占地行为；二是对卫片执法图斑整改重视不够，整改工作推进滞后；三是农村宅基地审批管理不规范，导致村民违法占地建房问题多发。

三、处理决定
   对××镇政府在全县范围内予以通报批评；责成××镇政府对相关责任人依法依规作出处理，处理结果于5月10日前报县纪委监委和县自然资源局备案。

四、工作要求
   各乡镇要深刻吸取教训，举一反三，切实履行耕地保护属地责任。一要严格执行农村宅基地审批制度，从源头上减少违法占地行为；二要加大日常巡查力度，做到违法占地行为早发现、早制止、早处置；三要对本辖区历年来卫片执法图斑逐宗梳理，确保存量问题限期清零。

                        ××县自然资源局
                        ××县农业农村局
                        2024年4月20日

```

## 五、函

**适用：** 不相隶属机关之间商洽工作。

**要点：** 语气平等，事项明确，用词精准。

### 典型实例

```

关于商请提供政务数据共享接口的函

县市场监督管理局：

根据《×市政数据共享管理办法》要求，我局在推进"一网通办"事项梳理过程中，需调用贵局企业登记注册基本信息（含统一社会信用代码、企业名称、法定代表人、经营范围等字段），用于市场准入审批业务联动核查。

恳请贵局协助提供相关数据接口的技术文档及对接联系人信息，并就数据更新频率、安全保障措施等事项进行沟通衔接。

如蒙函复，请联系县政务服务管理局信息技术科，联系人：李××，联系电话：××××。

                        ××县政务服务管理局
                        2024年3月5日

```

## 六、纪要

### 模板

```

[会议名称]纪要

一、会议基本情况（时间/地点/主持人/参会人员）
二、会议议题
三、议定事项（责任单位 + 完成时限）
四、需要说明的问题

```

**要点：** 不写讨论过程，议定事项"三明确"（明确事项/责任/时限）。

### 纪要"虚实结构法"（先虚后实）

> 先表明立场态度，再部署具体任务。

```

【虚——一致意见】
  "会议认为""会议指出""会议强调"开头
  → 表达对某一事项的一致看法和判断

【实——具体决定】
  "会议明确""会议要求""会议议定"开头
  → 明确具体事项：谁来做、做什么、什么时限

```

### 典型实例

```

全县一季度经济运行分析会纪要

2024年4月3日，县委副书记、县长×××主持召开全县一季度经济运行分析会。

一、会议基本情况
   时间：4月3日（星期三）上午9:00
   地点：县政府四楼会议室
   主持：县委副书记、县长×××
   参会：各副县长、有关部门主要负责人、各乡镇长

二、会议议题
   听取一季度经济运行情况汇报，分析当前形势，部署二季度重点经济工作。

三、议定事项
   （一）关于工业经济。会议明确，二季度要紧盯全年规上工业产值目标不放松，县经信局负责研究出台支持制造业企业稳产达产的专项措施，4月底前形成送审稿。（责任单位：县经信局；完成时限：4月30日）
   （二）关于招商引资。会议议定，二季度至少组织两次外出招商活动，重点对接珠三角、长三角地区装备制造企业；县招商中心负责制定具体方案，报分管副县长审定后实施。（责任单位：县招商中心；完成时限：4月15日）
   （三）关于项目建设。会议明确，对一季度已开工但进展缓慢的12个重点项目，实行"周调度、月通报"制度；对连续两个月进度滞后的项目责任单位，由县政府分管领导约谈其主要负责人。（责任单位：县发改委；完成时限：长期坚持）

四、需要说明的问题
   会议指出，当前房地产市场持续低迷对我县固定资产投资形成较大下行压力，县住建局要密切跟踪市场动态，研究提出促进房地产市场平稳健康发展的对策建议，提交下次常务会议审议。

                        ××县人民政府办公室（整理）
                        2024年4月5日

```

### 纪要写作四忌

1. ❌ 不善于概括归纳，内容杂乱零散
2. ❌ 把纪要与文件混为一谈，搞得不伦不类
3. ❌ 记述不具体、不准确
4. ❌ 不恰当地突出领导讲话，使纪要变成讲话传达稿

## 七、决定

### 模板

```

关于[事项]的决定

[主送机关]：

一、作出决定的目的/依据
二、决定事项（逐条列出）
三、执行要求

```

**要点：** 语气庄重，事项明确，可操作。

## 八、决议

### 两种类型，严格区分

| 类型 | 适用场景 | 写法特征 |
|------|---------|---------|
| **决策性决议** | 就某一重大问题作出决策 | 目标任务+措施方法，有小标题；结尾可有号召语 |
| **批准性决议** | 审议工作报告，具法定程序性 | 篇幅短小，一般不需小标题；大量使用"会议认为""会议号召" |

> ⚠️ 文体选错的后果：把批准性决议写成决策性决议，格式和语气都不对。

## 九～十五、命令、公告、通告、议案、意见、批复、指示

**通用原则：**

- **文种选对**——选错文种，格式全废
- **格式规范**——标题四要素 + 主送 + 正文 + 落款
- **语言得体**——符合文种的语气要求
- **程序合规**——签发/会签/分发

> 更多文种的详细模板与范例，可参照 GB/T 9704-2012《党政机关公文格式》国家标准，并结合本单位具体规范执行。
