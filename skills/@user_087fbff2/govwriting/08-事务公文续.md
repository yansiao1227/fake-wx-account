# 事务公文续篇

### 5.10 讲话稿五类专项（v3.1.1 新增）



> 讲话稿不是一种文种，而是五种。每种的语言风格、结构要求、写作难度都不同。



**第一类：总结表彰类讲话（难度★★☆）**



**场景：** 年终总结会、表彰大会



**结构：**

===

开场：肯定成绩（语气温暖，忌冷冰冰）

主体：总结经验（不只说"做了什么事"，要提炼"为什么能做好"）

结尾：展望未来（提出希望，鼓舞士气）

===



**写作要点：**

- 开头肯定成绩时要具体（举一两个典型事例，不要泛泛而谈"取得了可喜成绩"）

- 总结经验要提炼规律（不是流水账，是"我们体会最深的是……"）

- 结尾要有温度（不是"散会"，是鼓励和展望）



---



**第二类：部署动员类讲话（难度★★★☆）**



**场景：** 动员大会、部署会、突破年动员



**结构：**

===

开场：简短有力（直奔主题，不穿靴戴帽）

主体：讲清三个问题

  → 为什么要做（形势/问题/紧迫性）

  → 要做什么（目标任务，具体到数字）

  → 怎么做（路径/方法/责任）

结尾：表态坚定（用命令语气，不能软弱）

===



**写作要点：**

- "为什么做"要有紧迫感，但不是空喊口号

- "做什么"要有具体目标（数字、位次、时间节点）

- "怎么做"要有操作路径（不是"加强协调"，是"成立领导小组、明确责任分工"）

- 结尾要有命令感："必须……""不得……""严肃追究……"



---



**第三类：座谈交流类讲话（难度★★★☆）**



**场景：** 座谈会、协商会、民主生活会



**结构：**

===

开场：表明态度（今天来听什么、抱着什么心态）

主体：围绕议题谈看法

  → 不一个人唱主角，让与会者多说

  → 自己的意见要坦诚，不讲套话

结尾：根据会议性质决定（表态/回应/总结）

===



**写作要点：**

- 这类讲话最难的是"不让人反感"：领导座谈时不能居高临下

- 要有真实观点（"我也有不同看法……"）

- 要能听进去批评（"赞扬的话听起来舒服，但容易让人迷糊；批评的话听起来不舒服，但可以使人清醒"）



---



**第四类：指导基层类讲话（难度★★★★☆）**



**场景：** 调研座谈、现场办公、下基层讲话



**结构：**

===

开场：肯定成绩或发现问题

主体：

  → 针对问题讲思路（不只讲原则，要讲具体怎么办）

  → 针对困难讲对策（下面最需要的是解决方案）

结尾：表态支持（我回去怎么推动这件事）

===



**写作要点：**

- 到基层讲话最忌讳的是"我讲三点意见，你回去好好落实"

- 要带着问题来，带着答案走——至少要有思路

- 承诺的事情要具体（不是"加大支持力度"，是"回去后两周内给你们答复"）



---



**第五类：礼仪应景类讲话（难度★★☆）**



**场景：** 节日致辞、庆典仪式、奠基仪式、欢迎仪式



**结构：**

===

开场：礼节性问候

主体：阐述意义（这个活动/节日/事件的意义）

结尾：提出希望/号召

===



**写作要点：**

- 篇幅短（3-5分钟，不超过800字）

- 语言要庄重优美（可以适当用修辞，但不要太过）

- 要有现场感（最好提到现场的具体人/事）



---



**一把手表态发言专项（v3.1.1 新增）**



> 一把手在大会上的表态发言，与副职完全不同：有决定权、有权威性、有示范效应。



**结构：**

===

简短开头（不自我表扬，不寒暄）

主体（用"三个表明"结构）：

  → 表明态度（我怎么看这个问题）

  → 表明决心（我们一定……）

  → 表明要求（对各级各部门的要求）

结尾（命令语气，不是商量口吻）

===



**一把手表态发言三忌：**

1. 忌用"我们"代替"我"（一把手要说"我"，有担当）

2. 忌语气软弱（不用"大概""可能""争取"，要用"一定""必须"）

3. 忌空表态（"我一定努力"没有意义，要有具体目标）

### 5.11 调研提纲六要素（v3.1.1 新增）



> 写调研报告前，先列提纲。提纲不过关，报告就废了。



**调研提纲六要素：**



| 要素 | 要回答的问题 | 写作提示 |

|------|------------|---------|

| **背景** | 为什么要做这个调研？ | 写1-2句，交代来由 |

| **目的** | 调研要解决什么问题？ | 一句话概括 |

| **对象** | 调研谁？看了什么？ | 具体名单/样本 |

| **方法** | 怎么调研的？ | 座谈会/实地考察/问卷 |

| **重点** | 重点了解什么？ | 3-5个核心问题 |

| **预期** | 预计能得出什么结论？ | 不是结论，是预判 |



**调研提纲示范：**

===

一、调研背景

  市委市政府提出加强生态治理和管护决策部署后，

  XX县在省内率先推行"多员合一"生态管护员制度。



二、调研目的

  总结该县的做法和成效，为面上推开提供参考。



三、调研对象

  XX县生态管护局、3个试点乡镇、10个生态管护员



四、调研方法

  实地走访+座谈+查阅台账



五、调研重点

  1. 制度设计是怎么形成的？

  2. "多员合一"整合了哪些职能？

  3. 待遇保障如何？

  4. 成效如何量化评估？



六、预期结论

  该制度可复制、可推广，建议在全市推开。

===

### 5.12 即兴/现场讲话要点（v3.1.1 新增）



> 即兴不是"不用准备"，而是"现场快速成稿"。考验的是积累和反应。



**即兴讲话四步法（30秒内完成）：**



1. **定调**（5秒）——听众是谁？气氛是什么？

2. **找角度**（10秒）——你对这个话题最想说什么？

3. **搭架子**（10秒）——一两个关键词，三句话概括

4. **展开**——用具体事例、数据或故事撑开



**即兴讲话三不：**

- 不重复别人的话（"刚才XX讲的很好，我完全同意"——然后没了）

- 不跑题（想到什么说什么，越说越远）

- 不说空话（"我觉得这个很重要"——说完就没了）



**现场应急讲话模板（可用于处理突发事件或回应突发情况）：**

===

一、现场表态（我知道了，我来处理）

二、初步判断（问题是什么）

三、处置原则（我们先做这三件事）

四、时限承诺（什么时候给你们答复）

===

### 5.12b 心得体会写作（v3.1.1 新增）



> 心得体会不是表态稿，是真正有感而发的文章。假心得一眼就能看出来。



**核心特征：**

- 真话实话最动听——有真实的感悟，不是空道理

- 小切口深挖掘——从一个具体话题切入，挖出深刻道理

- 叙议结合——不是纯粹叙事，也不是纯粹议论



**三种常见类型：**



**类型一：学习体会（最常见）**



结构：

===

一、学习了什么（引出话题）

二、为什么有感触（结合自身经历或现实问题）

三、悟出了什么道理（核心感悟，文章的主心骨）

四、今后怎么做（实践要求，落到行动）

===



写作要点：

- 从"大"往"小"切入：不要从"党的光辉历程"讲起，从"自己的感受"讲起

- 感悟要有独特性：不是"通过学习，我认识到……"（这是所有人的套话）

- 要有自我剖析：敢于承认自己的困惑、不适应，才能写出真实感



**类型二：工作反思**



结构：

===

一、面对什么问题（具体问题）

二、自己怎么想（内心过程）

三、今后打算怎么办（行动承诺）

===



**心得体会三原则（来自谢亦森标杆范文评析）：**



> "真话实话最动听。假心得一眼就能看出来——因为它没有真实感悟，没有具体分析，只有政治表态。"

>

> （来自谢亦森《大手笔》第十六章评析）



**常见错误：**

- 写成学习心得的"大帽子"（"在党的正确领导下，我认真学习了……"）

- 只有表态没有感悟（"我一定要……"——但为什么？悟到了什么？）

- 感悟不具体（"通过学习，我提高了认识"——怎么提高的？认识了什么？）

### 5.12c 群众座谈讲话（v3.1.1 新增）



> 群众座谈讲话最怕的是"话不投机半句多"——群众不爱听官话。写这类讲话的关键是"放下架子，说群众的话"。



**核心原则（来自谢亦森标杆范文评析）：**



> "这篇讲话，没有居高临下的'官气'，没有空洞的理论、生硬的说教和华丽的辞藻，而是像拉家常那样，以朴实、亲切、谦恭的语言与群众进行思想感情交流。"

>

> （来自谢亦森《大手笔》第十六章评析）



**结构：**

===

一、开场：表明来意（不是来检查，是来听取意见）

二、主体：

  → 认真听取意见（不要急于表态）

  → 有针对性地回应（能解决的当场承诺，不能解决的解释原因）

三、结尾：表态改进（回去后怎么办，给群众一个交代）

===



**语言风格要求：**

- 少用"贯彻落实"——换成"把这事办实"

- 少用"各位领导"——换成"乡亲们""各位老同志"

- 善用"大白话"——"实话实说""心里话"

- 承诺要具体——不是"尽快研究"，而是"回去之后两周内给你们答复"



**四不要：**

1. **不要居高临下**——群众不需要被教育，需要被尊重

2. **不要只讲大道理**——空洞理论不如具体承诺

3. **不要回避问题**——群众能看出来你是在敷衍

4. **不要当场拍板一切**——做不到的事不乱承诺



**标杆开场白：**

> "今天我和XX同志一起来，是来听大家说真话、实话的。作为领导干部，我们经常听到很多好听的话、赞扬的话甚至是奉承的话，赞扬的话听起来舒服，但容易让人迷糊；批评的话听起来不舒服，但可以使人清醒。"

### 5.12d 演讲比赛写作（v3.1.1 新增）



> 演讲比赛是最考验文字功底的场合——评委现场打分，没有修改机会。好演讲有五个标志：情感真、语言活、事例小、结构清、立意高。



**五种常见演讲类型：**



| 类型 | 场景 | 难度 |

|------|------|------|

| 主题演讲 | 歌咏比赛、主题宣讲 | ★★☆ |

| 竞职演讲 | 竞争上岗 | ★★★ |

| 即兴演讲 | 临时发言 | ★★★★ |

| 事迹报告 | 先进事迹宣讲 | ★★★ |

| 闭幕致辞 | 会议总结 | ★★☆ |



**好演讲的五个标志（来自谢亦森标杆评析）：**



> "篇幅不长，但内容实在，感情真挚，一名窗口工作者的敬业爱岗精神和无私奉献情怀跃然纸上。全文紧扣'平凡''奉献'等几个关键词，既有生动的比喻，又有朴实的叙述，既有深刻的感悟，又有强烈的抒情，以工作的平凡而烘托出精神的不平凡，具有较强的说服力和感染力。"

>

> （来自谢亦森《大手笔》第十六章评析）



**竞职演讲标杆四要素（来自谢亦森实测范文评析）：**



> "这篇竞职演讲兼具多种优点，思路开阔，语势畅达，自信而不失谦和，平实而不失风雅，充分展示了一名年轻文秘工作者高远的志向、蓬勃的朝气和干事创业的激情。"

>

> （来自谢亦森《大手笔》第十六章评析）



1. **自信而不失谦和**——敢于展示自己，但姿态谦恭

2. **平实而不失风雅**——有文采但不做作，不用生僻词

3. **语势畅达**——节奏感强，长短句交错，适合口头表达

4. **有具体支撑**——不用"工作能力强"，用"起草材料XX份，获得批示XX次"



**演讲开头的五种方法：**

1. **设问开场**——用一个发人深省的问题抓住听众

2. **名言开场**——用一句切题的名言或古语引出主题

3. **故事开场**——用一个简短故事或亲身经历切入

4. **排比开场**——用一组排比句制造气势

5. **自嘲开场**——用适度的自嘲拉近与听众的距离



**演讲结尾的四种方法：**

1. **总结升华**——把前面的内容浓缩成一个核心观点

2. **发出号召**——用"让我们……"号召行动

3. **引用名言**——用切题的名言或诗词收尾

4. **自编对联**——用对仗工整的对联展示文采（竞职专用）



**竞职演讲标杆结尾：**

> "最后以一首自编的对联来结束我的演讲，上联是'胜固可喜，宠辱不惊看花开'，下联是'败亦无悔，去留无意随云卷'，横批是'与时俱进'。"
