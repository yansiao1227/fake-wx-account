# 常用事务性公文（上）



### 5.9 汇报材料



> 汇报材料是给上级领导看的。领导时间有限，必须在最短时间内说清楚最重要的事。
>
> **核心标准："少讲过程，多讲实质；少讲空话，多讲实话；少讲一般，讲重点特色。"**
> —— 谢亦森《大手笔是怎样炼成的》



**汇报材料三原则（写前必问）：**

| 原则 | 怎么做 | 错误示范 |
|------|--------|---------|
| **少讲过程** | 开了多少会、研究了几次——几句话带过 | "我们先后召开X次会议进行研究部署" |
| **多讲实质** | 直接说结论、说成效、说问题 | "成效主要体现在：一是……" |
| **少讲空话** | 不写政治表态，写具体事实 | "在上级正确领导下"——这句可以删 |
| **多讲实话** | 用数字和案例支撑 | "共解决问题XX个" |
| **少讲一般** | 不写大家都知道的通用内容 | "加强了组织领导" |
| **讲重点特色** | 重点讲本地本单位的独特做法和亮点 | "我们重点抓了XX工作" |



**汇报材料标准结构：**

```

一、基本情况
  → 1段话，让领导快速了解全貌；简洁概括，不从背景讲起

二、主要工作及成效（核心部分）
  → 按类别分，不按时间顺序
  → 每个类别：做法+成效，用数字说话
  → 亮点前置：最重要的放在最前面

三、存在问题（如实汇报，不回避）
  → 问题要具体，不泛泛而谈"工作有待加强"

四、恳请解决的问题（如有）

五、下一步打算（简要）
  → 要可操作，不写空话

```



**"深、准、实、紧"四字检验法：**

| 字 | 检验什么 |
|----|---------|
| **深** | 问题抓得准不准？原因分析透不透？ |
| **准** | 判断是否有数据或事实支撑？ |
| **实** | 对策措施能不能落地？ |
| **紧** | 逻辑是否环环相扣？ |

> **标杆评析（谢亦森）：**"情况清楚，事实准确，以数字说话，工作成效一目了然；篇幅简短，文字朴素，详略得当，没有废话；既有情况回顾，又有理性思考，抓住了根本问题。"

### 5.10 信息写作



> 信息是党政机关最常见、最高频的文种，是向上级反映情况、提出建议的快捷通道。一事一议，篇幅短小，言简意赅。



**三种类型框架：**



| 类型 | 标题写法 | 结构 |
|------|---------|------|
| **经验类信息** | 做法+成效（一句话概括） | 做法（怎么做的）→ 成效（数据说话） |
| **建议类信息** | 问题+对策（针对什么、建议什么） | 问题现状（数据支撑）→ 原因分析 → 对策建议（一一对应） |
| **问题类信息** | 事件+影响 | 事实经过 → 问题性质 → 初步处理 → 启示建议 |



**信息写作三忌：**

1. 忌写成简报——信息要提炼观点，不是流水账
2. 忌标题模糊——标题要让人一看就知道要说什么
3. 忌空洞无据——每个判断都要有数据或事实支撑



**信息写作四标准：**

- **标题醒目**：让人一眼看出要说什么
- **开门见山**：不穿靴戴帽，直奔主题
- **言简意赅**：篇幅短小，一事一议
- **主旨鲜明**：每个信息只说一件事

### 5.1 调研报告



**标准结构：**

```

一、调研概况（时间/对象/方法/样本量）
二、基本情况（调查对象的客观描述）
三、问题分析（揭示规律，分析原因）
四、对策建议（针对性、可操作）

```



**四种类型（决定框架和详略）：**

| 类型 | 适用场景 | 框架重点 |
|------|---------|---------|
| **总结经验类** | 某地某单位做法值得推广 | 做法→成效，重点在做法 |
| **揭示问题类** | 某种负面现象需引起重视 | 现状→原因→危害→对策 |
| **工作研讨类** | 全面工作分析，明确思路 | 成效→问题→对策，平衡写 |
| **决策依据类** | 决策前摸清情况 | 客观描述→利弊分析→选项建议 |



**"深、准、实、紧"四字标准：**

- **深**：看得透，抓住本质，不停留于表面
- **准**：判断对，数据说话，结论有充分依据
- **实**：措施实，能落地，不是空话
- **紧**：逻辑紧，环环相扣，没有跳跃

### 5.2 领导讲话稿



**万能结构：**

```
开场（切题入题，3-5分钟）
  → 肯定成绩（统一认识，2-3分钟）
    → 分析问题（认清形势，5-8分钟）
      → 部署工作（核心部分，10-20分钟）
        → 提出要求（落实保障，3-5分钟）
          → 结尾（号召或总结，1-2分钟）
```

> 节奏说明：开场3-5分钟进正题；分析问题不能少于部署工作；结尾要有力量，不要虎头蛇尾。



**三类讲话稿要点：**

| 类型 | 开头 | 中间 | 结尾 |
|------|------|------|------|
| **工作会议讲话** | "下面，我讲三点意见" | 每部分用"一、二、三" | 强调落实 |
| **动员部署讲话** | 简短有力 | 讲清"为什么/做什么/怎么做" | 表态坚定 |
| **总结表彰讲话** | 肯定成绩，语气温暖 | 总结经验，不只说"做了以下工作" | 展望未来 |



**特别提醒：**

- 研究领导的语言习惯——务实型还是激情型？
- 留出念稿时自然停顿的空间——适当分段，不写超长句
- 数据要核实——领导念错数字，影响极大
