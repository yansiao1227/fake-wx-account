This build focuses exclusively on WeChat. The Web Console remains available for configuration, diagnostics, and browser-based chat.

## Supported Channels

| Channel | Purpose |
| --- | --- |
| [Web Console](/channels/web) | Built-in management and chat console |
| [WeChat](/channels/weixin) | Official Weixin interface with QR login |
| [WeChat Desktop](/channels/wechat-desktop) | WeChat 4.x automation through Windows UI Automation |

Set `channel_type` to one or more of `web`, `weixin`, and `wechat_desktop`.
