title: 通道概览
description: CowAgent 支持的微信通道与 Web 控制台
---

当前项目只面向微信场景。Web 控制台继续用于配置、诊断和浏览器对话。

## 保留的通道

| 通道 | 用途 |
| --- | --- |
| [Web 控制台](/zh/channels/web) | 内置管理和聊天控制台 |
| [微信官方接口](/zh/channels/weixin) | 通过二维码登录的微信官方接口 |
| [微信桌面版](/zh/channels/wechat-desktop) | 基于 Windows UI Automation 的微信 4.x 桌面自动化 |

`channel_type` 仅支持 `web`、`weixin` 和 `wechat_desktop`，也可以组合启用。
