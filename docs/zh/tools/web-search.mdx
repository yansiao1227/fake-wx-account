搜索互联网获取实时信息、新闻、研究等内容。默认流程：先用百度千帆 **智能 Query 改写** 优化检索词，再并行调用 **百度 / Tavily / DDGS** 三源搜索，按关联度排序后返回最相关结果供大模型汇总。

另支持博查、智谱、LinkAI 等后端（`fixed` 策略或三源均不可用时的回退）。

<Note>
  火山引擎 **豆包搜索** 是独立工具：[`doubao_search`](/zh/tools/doubao-search)，**不是** `web_search` 的厂商。优先降级链：`doubao_search` → `baidu_ai_search` → `web_search`。
</Note>

<Tip>
  对一般事实问答与时效性问题，优先使用 [`baidu_ai_search`](/zh/tools/baidu-ai-search)（智能搜索生成草稿+来源，由 Agent 汇总）；其日额度用尽时会自动退化为本工具。
</Tip>

<Tip>
  推荐通过 [Web 控制台](/zh/channels/web) 的「模型管理 → 搜索」面板可视化配置厂商与策略，无需手动编辑配置文件。
</Tip>

## 默认流水线

1. **Query 改写**：`POST /v2/tools/query_rewrite`，使用 `QIANFAN_API_KEY`（`~/.cow/.env`）。文档见 [智能 Query 改写](https://cloud.baidu.com/doc/qianfan-api/s/tmokwnznj)。
2. **三源并行**：将 `altered_query` 同时发给百度千帆搜索、Tavily、DDGS（已配置/可用的）。
3. **关联度排序**：按 URL 去重，结合标题/摘要与 query 的词面重合、厂商自带 score、多源命中等打分，取 top-N 返回。

改写失败（含超时）时**不重试**，直接用原始 query 搜索。改写/百度/Tavily 若返回额度或限流类错误，会写入**当日失效标志**，当天后续调用跳过该能力，避免重复无效请求。不再对百度/Tavily 做本地请求次数预占计数。

## 厂商

| 厂商 | 凭证 | 申请入口 |
| --- | --- | --- |
| 百度千帆（搜索 + Query 改写） | 复用 `qianfan_api_key` / `QIANFAN_API_KEY` | [千帆控制台](https://cloud.baidu.com/doc/qianfan/s/2mh4su4uy) |
| Tavily | `tools.web_search.tavily_api_key` / `TAVILY_API_KEY` | [Tavily](https://tavily.com/) |
| DDGS | 无需凭证 | 安装 `ddgs` Python 包 |
| 博查 Bocha | `tools.web_search.bocha_api_key` | [博查开放平台](https://open.bochaai.com/) |
| 智谱 Zhipu | 复用 `zhipu_ai_api_key` | [智谱开放平台](https://docs.bigmodel.cn/cn/guide/tools/web-search) |
| LinkAI | 复用 `linkai_api_key` | [LinkAI 控制台](https://link-ai.tech/console/interface) |

## 路由策略

```json
{
  "tools": {
    "web_search": {
      "strategy": "auto",
      "provider": "",
      "query_rewrite": true,
      "ddgs_backend": "bing,brave",
      "ddgs_region": "cn-zh"
    }
  }
}
```

- `auto`（默认）：Query 改写后并行 fan-out 到 `qianfan → tavily → ddgs`；部分源失败不影响其他源；三源皆不可用时再回退博查/智谱/LinkAI。
- `fixed`：固定使用 `provider` 指定的厂商（仍会先做 Query 改写）；该厂商不可用时回落到 auto 多源。
- `query_rewrite`：是否启用改写，默认 `true`。
- `ddgs_backend`：DDGS 内部引擎列表，默认 `bing,brave`，以逗号分隔。
- `ddgs_region`：DDGS 搜索区域，默认 `cn-zh`。

## 工具参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `query` | string | 是 | 搜索关键词 |
| `count` | integer | 否 | 返回结果数量（1–50，默认 10） |
| `freshness` | string | 否 | 时间范围：`noLimit`（默认）、`oneDay`、`oneWeek`、`oneMonth`、`oneYear`，或日期范围如 `2025-01-01..2025-02-01` |
| `summary` | boolean | 否 | 是否返回页面摘要（默认 false） |
| `provider` | string | 否 | `auto` 策略下配置了多个厂商时可见，用于单次切换厂商 |

<Note>
  四家 API 凭证均未配置时，只要运行环境安装了 `ddgs`，工具仍会注册并使用 DDGS。若 DDGS 也未安装，该工具不会注册到 Agent。
</Note>

## 引用要求

只要回答使用了 `web_search` 返回的信息，就必须以可点击链接引用支持该事实的搜索结果 URL。不要输出没有来源链接的搜索衍生事实。该要求同时写入工具描述和每次成功调用的 `citationPolicy` 返回字段，避免模型在拿到结果后遗漏引用。
