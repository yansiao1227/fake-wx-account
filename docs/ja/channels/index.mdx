---
title: チャンネル概要
description: CowAgent が対応する WeChat チャンネルと Web コンソール
---

このビルドは WeChat 専用です。Web コンソールは設定、診断、ブラウザチャットに使用できます。

## 対応チャンネル

| チャンネル | 用途 |
| --- | --- |
| [Web コンソール](/ja/channels/web) | 組み込みの管理・チャットコンソール |
| [WeChat](/ja/channels/weixin) | QR ログインを使用する公式 Weixin インターフェース |
| WeChat Desktop | Windows UI Automation による WeChat 4.x デスクトップ自動化 |

`channel_type` には `web`、`weixin`、`wechat_desktop` のみ指定できます。
